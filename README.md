# C# and .NET Framework — Part 2 Projects

This repository contains projects I developed while studying C# and .NET Framework — Part 2 at Academy of Learning Career College. They demonstrate console applications, web development, and database access using C#.

## Featured Projects

### BlackJack Game

A console application that simulates the casino card game Blackjack. It includes player and dealer actions, card handling, and score calculations.

**Technologies:** C#, .NET Framework

### CarInsurance

An ASP.NET Core MVC web application that calculates monthly insurance quotes using age, vehicle details, speeding tickets, DUI history, and coverage type.

The application validates user input, saves records to a SQL Server database, and includes an Admin page displaying customers and their quotes.

**Technologies:** C#, ASP.NET Core MVC, Entity Framework Core, SQL Server

[View the CarInsurance project](./Module_12B_CarInsurance/)

### CodeFirstStudent

A console application demonstrating Entity Framework's Code First approach. C# classes define the student and grade models. Entity Framework creates the database and tables, and the application adds a student record.

**Technologies:** C#, .NET Framework, Entity Framework 6, SQL Server LocalDB

[View the CodeFirstStudent project](./Module_12_Final_CodeFirstStudent/)

## Skills Gained

- **C#:** Writing application logic using classes, methods, interfaces, inheritance, and polymorphism.
- **Exception handling:** Using try/catch blocks to handle errors.
- **ASP.NET Core MVC:** Organizing web applications into models, views, and controllers.
- **Input validation:** Checking user input and displaying helpful error messages.
- **Entity Framework:** Connecting C# models to relational databases using EF6 and EF Core.
- **Code First and migrations:** Creating databases from C# models and updating database structures as models change.
- **SQL Server:** Storing and retrieving application data.
- **Git and GitHub:** Tracking changes and publishing project source code.
